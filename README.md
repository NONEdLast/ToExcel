# 文档转Excel工具

一个功能强大的文档转Excel工具集，支持将TXT和JSON文件转换为Excel格式，并提供友好的Web界面。

## 项目简介

**文档转Excel工具**是一款专为数据处理人员设计的高效转换工具，旨在简化从文本文件和JSON数据到Excel表格的转换流程。该工具不仅提供了命令行和图形界面两种使用方式，还支持数据的实时编辑和预览，极大地提高了数据处理的效率和准确性。

### 项目背景

在日常工作中，我们经常需要将结构化文本或JSON数据转换为Excel表格进行进一步分析和处理。传统的转换方式往往需要手动处理，耗时且容易出错。本工具的出现旨在解决这一痛点，提供自动化、智能化的数据转换方案。

### 主要特点

- **多格式支持**：无缝处理TXT（支持多种分隔符）、JSON（支持多种结构）文件
- **双界面设计**：既有适合批量处理的命令行工具，也有直观易用的Web界面
- **智能转换**：自动识别数据格式、表头信息和函数定义
- **实时预览**：在Web界面中可实时查看转换结果和进行表格编辑
- **安全可靠**：本地运行，数据不上传至云端，保护隐私安全
- **丰富功能**：支持Excel函数转换、排序工作表生成等高级功能

### 使用场景

- **数据分析**：将日志文件、API响应等转换为Excel进行分析
- **报表生成**：快速将结构化数据转换为标准格式的报表
- **数据迁移**：在不同系统间进行数据格式转换和迁移
- **日常办公**：简化繁琐的数据整理工作，提高工作效率

### 技术栈

- **Python**：核心开发语言，提供强大的数据处理能力
- **Pandas**：用于数据结构和数据分析
- **OpenPyXL**：用于Excel文件的读写操作和函数计算
- **SQLite3**：用于SQLite数据库的连接和操作
- **Gradio**：用于构建友好的Web界面
- **JSON**：用于数据格式处理

## 核心功能模块

### 1. TXT转Excel (txt_to_excel.py)
轻松将文本文件转换为Excel表格，智能处理各种格式的TXT文件：
- 自动识别文件中的分隔符（如逗号、制表符、空格等）
- 智能判断是否包含表头信息
- 生成包含原始数据的工作表
- 自动为每一列创建降序排序的工作表，方便数据分析
- 完善的错误处理，确保转换过程稳定可靠
- 自动处理重名文件，避免文件冲突

### 2. JSON转Excel (json_to_excel.py)
灵活处理多种结构的JSON数据，一键转换为Excel表格：
- 支持三种常见JSON格式：
  - 列表格式：`[{"姓名": "张三", "年龄": 25}, {"姓名": "李四", "年龄": 30}]`
  - 嵌套字典：`{"员工1": {"姓名": "张三"}, "员工2": {"姓名": "李四"}}`
  - 字典格式：`{"姓名": ["张三", "李四"], "年龄": [25, 30]}`
- 自动将文本形式的数字转换为Excel数字类型
- 支持在JSON中定义Excel函数（如SUM、AVERAGE等）
- 生成原始数据和排序后的工作表

### 3. SQLite与Excel转换 (sqlite_to_excel.py)
实现SQLite数据库与Excel表格之间的双向转换：
- **SQLite转Excel**：支持将整个数据库或指定表转换为Excel文件
- **Excel转SQLite**：支持将Excel工作表转换为SQLite数据库表
- **函数计算**：自动计算Excel中的函数并将结果存储到SQLite
- **灵活配置**：支持选择特定表、设置Unicode排序、自定义表名等
- **批量处理**：支持同时转换多个表
- **安全可靠**：支持文件权限和存在性检查，提供详细的错误信息

### 4. Gradio Web界面 (gradio_app.py)
提供直观易用的可视化界面，无需命令行操作：
- 简单的文件上传功能
- 实时预览转换结果并下载
- 支持对表格进行行和列的增删改操作
- 一键下载转换好的Excel文件
- 内置SQLite转换功能，支持数据库与Excel的双向转换
- 内置详细的使用说明
- 本地运行，数据不上传至云端，保护隐私

## 快速使用指南

### 1. 命令行方式（适合批量处理）

#### TXT转Excel
```bash
python txt_to_excel.py 你的文件.txt
```

#### JSON转Excel
```bash
python json_to_excel.py 你的文件.json
```

#### SQLite转Excel
```bash
python sqlite_to_excel.py --sqlite-to-excel 你的数据库.db 输出文件.xlsx
```

#### Excel转SQLite
```bash
python sqlite_to_excel.py --excel-to-sqlite 你的文件.xlsx 输出数据库.db
```

也可以使用批处理文件：
```bash
run_json_to_excel.bat 你的文件.json
```

### 2. 网页界面方式（适合快速转换）

1. 双击运行 `run_gradio.bat` 文件
2. 在浏览器中打开 `http://127.0.0.1:7861`（注意：端口已从7860改为7861）
3. 选择要转换的文件类型选项卡：
   - TXT转Excel
   - JSON转Excel
   - SQLite转换（新增功能）
4. 上传文件并点击转换按钮
5. 查看预览结果并下载转换后的文件

#### SQLite转换功能使用

1. 在Web界面中选择"SQLite转换"选项卡
2. **SQLite转Excel**：
   - 上传SQLite数据库文件（.db）
   - 可选：输入要转换的表名（多个表用逗号分隔）
   - 可选：勾选按Unicode排序字段名
   - 点击"SQLite转Excel"按钮
   - 下载生成的Excel文件
3. **Excel转SQLite**：
   - 上传Excel文件（.xlsx或.xls）
   - 可选：输入要创建的表名
   - 点击"Excel转SQLite"按钮
   - 下载生成的SQLite数据库文件

## 常见问题解答

### Q: 为什么转换后的Excel文件没有表头？
A: 工具会自动尝试识别表头，如果未识别成功，可以手动在生成的Excel文件中设置表头。

### Q: 支持哪些函数类型？
A: 目前支持SUM（求和）、AVERAGE（平均值）、MAX（最大值）、MIN（最小值）等常用函数。

### Q: 如何处理大型文件？
A: 对于大型文件，建议使用命令行方式，转换速度更快。

### Q: 转换后的文件保存在哪里？
A: 转换后的Excel文件会保存在与源文件相同的目录中，文件名与源文件保持一致。

## JSON函数定义格式

JSON转Excel工具支持在JSON中定义函数，格式如下：

```json
{
  "col3": {
    "type": "SUM",  // 函数类型
    "sub": [         // 要计算的单元格
      {"r": -2, "c": 0},  // r: 相对行数, c: 相对列数
      {"r": -1, "c": 0}
    ]
  }
}
```

支持的函数类型：
- SUM: 求和
- AVERAGE: 平均值
- MAX: 最大值
- MIN: 最小值

相对位置说明：
- r: 相对当前行的偏移（负数表示上方行，正数表示下方行）
- c: 相对当前列的偏移（负数表示左侧列，正数表示右侧列）
